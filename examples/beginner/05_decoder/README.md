# Decoder Example

A binary-to-one-hot decoder with enable control.

## Features

- Parameterized address width
- Automatic output width calculation (2^N)
- Enable control
- Pure combinational logic

## Use Cases

- Address decoding
- Chip select generation
- Memory address mapping
- Peripheral selection

## Learning Objectives

- Binary to one-hot conversion
- Width calculation with bit shifts
- Enable logic
- Decoder implementation patterns
