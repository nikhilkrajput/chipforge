# Multiplexer Example

A parameterized multiplexer for selecting one of many inputs.

## Features

- Configurable data width
- Configurable number of inputs
- Automatic address width calculation
- Pure combinational logic

## Use Cases

- Data path selection
- Bus routing
- Input selection for ALUs
- Configuration selection

## Learning Objectives

- Parameterization with $clog2
- Array ports
- Integer loops in always blocks
- Combinational logic design
