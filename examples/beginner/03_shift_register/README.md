# Shift Register Example

A versatile shift register with parallel load capability.

## Features

- Configurable width
- Serial input/output
- Parallel load
- Parallel output
- Shift enable control

## Use Cases

- Serial-to-parallel conversion
- Parallel-to-serial conversion
- Data delay lines
- Pattern generation
- Pseudo-random number generation (with feedback)

## Learning Objectives

- Bit manipulation in Verilog
- Concatenation operator
- Part-select operations
- Multiple control signals
- Priority encoding in sequential logic
