# SPI Master Controller

Full-featured SPI (Serial Peripheral Interface) master implementation.

## Features

- Configurable clock divider
- Full-duplex communication
- Mode 0 (CPOL=0, CPHA=0)
- Automatic chip select control
- Busy/done handshaking

## SPI Protocol

- **SCLK**: Serial clock (generated by master)
- **MOSI**: Master Out, Slave In
- **MISO**: Master In, Slave Out
- **CS_N**: Chip Select (active low)

## Usage

1. Assert `start` with `tx_data` to begin transfer
2. Wait for `busy` to go low
3. Read `rx_data` when `done` pulses high

- SPI protocol implementation
- Clock divider design
- Shift register usage
