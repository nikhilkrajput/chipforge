# Synchronous FIFO

First-In-First-Out buffer with status signals.

## Features

- Parameterized width and depth
- Full/empty flags
- Count output
- Single clock domain
- Simple pointer-based design

## Use Cases

- Data buffering
- Rate matching
- Pipeline decoupling
- Burst handling

## Learning Objectives

- Memory inference
- Pointer management
- Status flag generation
- Concurrent read/write
