## [0.1.0] - 2024-11-21

### Added
- Initial project structure and workspace setup
- Core common library with error handling, identifiers, types, and graph utilities
- Basic synthesis engine with Verilog lexer
- CLI tool with commands: new, synthesize, simulate, analyze
- Comprehensive documentation structure
- CI/CD pipeline with GitHub Actions
- MIT and Apache-2.0 dual licensing
- Code of Conduct and Contributing guidelines

### Infrastructure
- Rust workspace with 20+ crates
- Modular architecture for synthesis, simulation, formal verification, P&R
- RISC-V ecosystem foundation
- Cloud and AI infrastructure stubs
- Plugin system foundation
