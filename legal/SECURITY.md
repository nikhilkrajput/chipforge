# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please follow these steps:

### DO NOT

- Open a public GitHub issue
- Discuss the vulnerability publicly
- Exploit the vulnerability

### DO

1. Email security@chipforge.org with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fixes (if any)

2. Allow up to 48 hours for initial response

3. Work with us to resolve the issue

## Response Timeline

- **48 hours**: Initial acknowledgment
- **7 days**: Preliminary assessment and plan
- **30 days**: Fix developed and tested
- **Disclosure**: Coordinated public disclosure after fix

## Scope

This policy applies to:
- ChipForge CLI tool
- ChipForge core libraries
- ChipForge cloud services
- ChipForge GUI application

## Out of Scope

- Third-party dependencies (report to their maintainers)
- Social engineering attacks
- Physical security issues

## Recognition

We maintain a Hall of Fame for security researchers who responsibly disclose vulnerabilities.
